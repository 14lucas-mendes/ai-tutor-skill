# Lesson Workflow

Select the next `planned` or resumable `in_progress` lesson whose prerequisites are satisfied. Do not infer eligibility from the last session alone.

For programming, read `references/programming.md` and treat the lesson as an adaptive set of teaching options, not a sequence that must be consumed. Create `lessons/<sequence>-<slug>.md` with the lesson ID, observable objective, project anchor, prerequisites, verified sources, a possible concrete example, scaffold options, independent-task variants, expected errors, evidence criteria, and state update instructions. Select, combine, revisit, or omit these components according to observed learner performance.

Transfer is required only when the targeted mastery level requires it under the learning contract. A solution supplied by the tutor remains study material. Complete the lesson only when its own criteria and evidence are present.
